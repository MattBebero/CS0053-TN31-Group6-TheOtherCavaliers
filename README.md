# Dungeons But No Dragons

A console turn-based battle game written in C++17 for 1 to 3 players on one keyboard.
CS0053 TN31 Final Group Project, Group 6 "The Other Cavaliers".

## Planned features

- Main menu with Play, Continue, Tutorial, Run History and Exit
- Party of 1 to 3 players, each choosing Swordsman, Ranger, Mage or Priest
- Turn-based battles over 10 stages, ending with a boss
- Types, MP, cooldowns and status effects (Poison, Burn, Bleed, Shield, Taunt)
- Save after every stage and Continue later
- Input validation on every menu

## Requirements

A C++17 compiler: g++ (MinGW-w64 on Windows) 9 or newer.
